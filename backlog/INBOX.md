# やりたいこと 受付

ここに書けば拾われます。**GitHub の web 上で直接編集して commit するのが一番早い**
（スマホからでもできる）。書式は「`-` で始まる行」だけ守れば、あとは自由。

毎朝 07:10 の harvester が `wl intake` でここを読み、wishlist に登録して、
この受付欄を空にします。取り込まれたかどうかは `backlog/journal.jsonl` を見れば
わかります。

## 書き方

```
- 領収書をまとめて経費精算する
- !! 請求書の締切が今週金曜 #経理
- ? このリポジトリを Python 3.13 に上げるべきか調べて #調査
- 古いブランチを整理する #掃除 (effort:1)
```

記号は全部おまけで、無くても動きます。

| 記号 | 意味 |
|---|---|
| `!` | 重要（`!` で value 4、`!!` で 5） |
| `?` | 決めてほしいことがある。調べて選択肢を出すだけで、勝手に実行しない |
| `#タグ` | 分類。あとで絞り込める |
| `(effort:N)` | 手間が 1〜5 でわかっているとき |
| `(due:2026-08-31)` | 締切。近づくと自動的に順位が上がる |

重要度を書かなくても、消化実績を見て prioritizer が毎朝 直します。
迷ったら何も付けずに一行書いてください。

## ほかの入口

- **チャットで言う** — セッション中に「〜やりたい」と言えば、その場で登録されます
- **手元の端末から** — `python3 engine/wl.py add "やりたいこと"`
