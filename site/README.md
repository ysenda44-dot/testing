# 多ブランドLP リファレンス帖

ラグジュアリーブランドのブティックを1ページで見せるLPのための、デザインリファレンス集（229件のカード、112行のスタジオ・年間賞、10の設計原則、チェックリスト）です。
`index.html` を開くと、絞り込みながら一覧できます。いまは画像がなく、各カードに仮の画像枠（カードのID、撮影元のホスト名、「画像未設定」）が出ています。

このファイルは、Codexが画像を追加するための手順書です。

## フォルダの構成

| パス | 役割 |
|---|---|
| `data/references.json` | 調査レポートから `tools/extract.py` が生成したデータ。手で編集しない |
| `data/images.json` | カードIDと画像パスの対応表。画像を足すたびにここを更新する（初期値は `{}`） |
| `images/` | 画像ファイルの置き場 |
| `src/page.html` | ページの雛形（デザインと動作）。`__DATA__` の行にデータが入る |
| `tools/build.py` | `index.html` を組み立てる |
| `index.html` | 生成物。直接編集しない |

`tools/extract.py` を再実行して `references.json` が作り直されても、画像の設定は `images.json` に別に持っているので消えません。

## 画像の追加手順

カード1件ごとに次の作業をします。

1. `data/references.json` の `cards[]` からカードを選ぶ。
2. 撮影するURLを決める。まず `shot_url` を開く。開けない、または別のページが適切なときは、同じカードの `shots[]` にある別のURLを使う。
3. ブラウザの表示領域を **1600×1000** にして、ページ上部（ファーストビュー）のスクリーンショットを撮る。ページ全体ではなく、最初に見える範囲だけにする。
   - Cookieの同意バナーや年齢確認、ログインの壁が出たら、閉じられるものは閉じてから撮る。閉じられないときは、そのままにして次の項目の備考に残す。
   - 動画やWebGLの読み込みを待つため、表示が落ち着いてから撮る（目安は読み込み後2〜3秒）。
4. `images/<カードID>.webp` として保存する（例：`images/B01.webp`）。WebPが使えなければ `.jpg` でもよい。
   - 横1600px、WebPの品質80前後で、1枚あたり200KB以下を目安にする。229枚そろえても全体で50MB前後に収まる。
5. `data/images.json` に、カードIDと画像パスを足す。パスは `site/` からの相対パスで書く。

   ```json
   {
     "B01": "images/B01.webp",
     "B02": "images/B02.webp"
   }
   ```

6. すべて終えたら、ビルドする。

   ```
   python3 site/tools/build.py
   ```

   `site/index.html` が作り直され、画像のあるカードは画像、ないカードは仮の画像枠で表示されます。
   `images.json` に書いたのにファイルがない場合や、外部URLを書いた場合は、ビルド時に警告が出て、そのカードは仮表示のままになります。

1枚ごとにビルドする必要はありません。何件かまとめて撮ってから、`images.json` を更新してビルドしてください。

## 撮影するURLの状態

`shots[]` の `status`（ページ内では「撮影元のURL」の横に表示）は、そのURLがどれだけ確かめられているかを表します。**どの状態でも、実際に開いて、正しいページか、見た目に使えるかを確認してから撮ってください。**

| 状態 | 意味 | 撮る前にやること |
|---|---|---|
| `seen` | 調査メモで「そのURLが検索結果に出た」と記録されたもの。ページの中身は誰も見ていない | 開いて、ブランドやキャンペーンのページか確かめる |
| `要確認：構築` | 調査者がURLの形から組み立てたもの。存在しない可能性がある | 開けるか確かめる。なければ検索して正しいURLを探す |
| `出典URL・要確認` | 出典として検索結果に出たURLを、撮影元の候補として転記したもの | 記事のページのことがある。作品そのもののページが別にあれば、そちらを撮る |
| `URL未検証` | 公式URLが検索結果に出ておらず、事前知識によるもの | 公式サイトを検索して探す |

状態の文末に「一覧ページ」「プロフィールページ」などの注記があるものは、一覧の中から該当する作品やブランドを開いて撮ります。
別のURLに差し替えたときは、`references.json` は編集せず、撮ったページのURLを下の「撮影メモ」に控えてください。

## claude.ai の Artifact として公開するとき

ページを Artifact として公開する場合は、画像も**ページと同時に、同じ相対パスのファイルとして**公開します。

- `index.html` が参照する `images/<カードID>.webp` を、公開時のファイル一覧（`files`）に、同じパスで加える。
- 画像は外部のURLから読み込めません。ページのCSP（コンテンツセキュリティポリシー）が外部画像をブロックするため、他サイトの画像を直接参照（ホットリンク）してはいけません。`images.json` にも `https://…` は書かないでください（書いてもビルドで無視されます）。
- 1回の公開で送れるのは、最大255ファイル、合計64MBまでです。画像が多いときは、何回かに分けて同じURLへ公開します。

```
カードID | 使ったURL | 備考
```
